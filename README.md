# Quiz Recall Roundabout

Создай мультиплатформенное веб-приложение (адаптивное под мобильный экран / Telegram Mini App и десктоп) для интервального повторения фактов и подготовки к интеллектуальным играм (ЧГК, Своя игра). Стек: React, TypeScript, Tailwind CSS, Lucide Icons, Supabase (Database + Storage).

Реализуй 4 основных раздела:

1. ЭКРАН «ТРЕНИРОВКА» (Конструктор сессии и плеер карточек):

- Перед стартом сессии пользователь выбирает:

  а) Источники: чекбоксы каналов/категорий (например, «Все каналы» или выборочно «Наука» + «Абстрактная бинга»).

  б) Направление карточек: «Обратное (Крючок → Термин)», «Прямое (Термин → Факты)» или «Вперемешку».

  в) Режим: «Только к повторению на сегодня» или «Свободная тренировка по всем карточкам раздела».

- Интерфейс карточки:

  - Сверху плашка с названием канала и бейдж направления («Угадай термин» или «Вспомни факты»).

  - Если у карточки есть image_url: в обратном режиме картинка показывается сразу, а в прямом — только после переворота карточки.

  - Переворот по клику или клавише Space.

  - После переворота отображаются Термин, Крючок, Полный текст заметки и 4 кнопки оценки по системе Лейтнера (с поддержкой клавиш 1, 2, 3, 4 на ноутбуке):

    1: «Не помню» (box = 0, вернуть в конец текущей сессии)

    2: «С трудом» (box = 1, через 1 день)

    3: «Помню» (box = 2, через 4 дня)

    4: «Железобетон» (box = 3, через 14 дней; если уже был 3 -> box = 4, через 45 дней).

  - У каждого направления (forward и reverse) свой независимый прогресс (box и due_at).

  - Кнопка быстрого редактирования (клавиша E), позволяющая прямо во время сессии поправить поля term, hook, full_text или сменить категорию.

2. ЭКРАН «БАЗА ЗНАНИЙ»:

- Полнотекстовый поиск по всем карточкам (по term, hook и full_text).

- Фильтр по каналам/категориям.

- Возможность вручную добавить новую карточку (с загрузкой картинки) или удалить старую.

- Индикаторы прогресса для каждой записи (две точки: статус прямого и обратного запоминания).

3. ЭКРАН «ИМПОРТ ИЗ TELEGRAM (result.json)»:

- Загрузка экспорта из Telegram Desktop: пользователь может выбрать либо один файл `result.json`, либо всю папку экспорта целиком (через input с атрибутом webkitdirectory), чтобы подхватились картинки из подпапки `photos/`.

- Клиентский парсер `result.json`:

  - Берёт массив `messages`, фильтрует только `type === "message"`.

  - Корректно собирает поле `text`: если `text` — массив, объединяет все строковые элементы и поля `.text` у объектов форматирования (`bold`, `link`, `italic` и др.).

  - Пропускает пустые сообщения без текста и без фото.

  - Показывает предпросмотр: сколько постов найдено, сколько из них с фото, и табличку первых 5 распарсенных постов.

- Настройки перед запуском импорта:

  - Выбор назначения: «Поместить всё в выбранный канал» ИЛИ «Автоматически распределить по существующим категориям через ИИ».

  - Чекбокс «Пропускать уже импортированные посты» (проверка по паре `source_chat_id` + `tg_message_id`).

- Пакетная обработка с прогресс-баром («Обработано X из Y», кнопки Пауза / Отмена):

  - Для каждого поста вызывается LLM API (через Supabase Edge Function или клиентский ключ из настроек), которая возвращает JSON: `{ "term": "короткий ответ 1-4 слова", "hook": "вопрос-крючок из 2-3 ключевых признаков без прямого называния ответа", "category_name": "название наиболее подходящей категории из списка" }`.

  - Если у поста есть поле `photo` (например, `"photos/photo_12.jpg"`) и пользователь загрузил папку с фото, файл загружается в Supabase Storage bucket `card-images`, а ссылка сохраняется в `image_url`.

4. ЭКРАН «СТАТИСТИКА И НАСТРОЙКИ»:

- Счётчик карточек к повторению на сегодня по каждому каналу.

- Управление списком каналов (создание, переименование, цвет). По умолчанию предустанови категории: «Литература и философия», «Наука и медицина», «История и быт», «Искусство», «Кино и сериалы», «Музыка», «География», «Спорт», «Абстрактная бинга».

- Поля для сохранения API-ключа LLM (если Edge Function не настроена) для работы авторазметки при импорте.

Дизайн: минималистичный, чистый, с поддержкой тёмной темы, крупными кнопками под большой палец на телефоне и горячими клавишами на десктопе. Подключи клиент Supabase через переменные окружения VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY и выведи полный SQL-скрипт для создания таблиц channels, cards (включая поля source_chat_id и tg_message_id для дедупликации) и публичного storage bucket `card-images`.
